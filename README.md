# Full Stack Open


### **A full-stack web development course from The University of Helsinki**



This repository documents my progress through [Full Stack Open](https://fullstackopen.com/en/about/), a comprehensive course in modern web development using JavaScript and TypeScript.

The course focuses on developing single-page applications with **React**, building **RESTful APIs with Node.js and Express**, and integrating databases. It also covers testing, authentication, state management, GraphQL, mobile development, CI/CD, and containerization.

## Course Contents

### Part 0 – Fundamentals of Web Apps
- HTTP and browser-server communication
- The DOM and web application architecture
- Single-page applications (SPAs)

### Part 1 – Introduction to React
- JavaScript fundamentals and JSX
- React components, props, and state
- Event handling and component rendering

### Part 2 – Communicating with Server
- REST APIs and HTTP requests
- Forms, collections, and event handling
- Asynchronous operations and server communication

### Part 3 – Programming a Server with Node.js and Express
- Backend development with Node.js and Express
- RESTful APIs, routing, and middleware
- MongoDB and Mongoose
- Application deployment

### Part 4 – Testing Express Servers and User Administration
- Backend unit and integration testing
- User management and authentication
- Authorization and JSON Web Tokens (JWT)

### Part 5 – Testing React Apps
- React component testing
- End-to-end testing
- React Router, UI frameworks, and styling

### Part 6 – Advanced State Management
- Global application state management
- Zustand and immutable state
- Server state management with TanStack Query

### Part 7 – Advanced React and Build Tools
- Custom React hooks
- Build tools: Vite and esbuild
- Error boundaries and application architecture

### Part 8 – GraphQL
- GraphQL API development
- Apollo Server and Apollo Client
- Queries, mutations, and subscriptions

### Part 9 – TypeScript
- Static typing and type safety
- TypeScript with React
- TypeScript with Node.js and Express

### Part 10 – React Native
- Cross-platform mobile development
- React Native and Expo
- Mobile UI components and navigation

### Part 11 – CI/CD
- Continuous integration and delivery
- Automated testing and deployment pipelines
- GitHub Actions

### Part 12 – Containers
- Docker and Docker Compose
- Containerized frontend and backend applications
- Environment and service configuration

### Part 13 – Relational Databases
- PostgreSQL and SQL
- Sequelize ORM
- Database migrations and relational data modeling

### Part 14 – Next.js
- Server-side rendering and React Server Components
- File-based routing and Server Actions
- Full-stack development with Next.js
